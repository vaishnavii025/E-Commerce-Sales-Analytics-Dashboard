# 📊 E-Commerce Sales Analytics Dashboard

An interactive E-Commerce Sales Analytics Dashboard developed using **Microsoft Power BI** to analyze sales performance, products, customers, and campaign effectiveness.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analytics

## 📌 Project Overview

This project focuses on analyzing e-commerce business data and transforming it into meaningful insights through interactive dashboards.

The dashboard contains four main sections:

1. **Sales Analysis** – Revenue, profit, orders, and sales performance.
2. **Product Analysis** – Product-wise sales and performance.
3. **Customer Analysis** – Customer trends and purchasing behavior.
4. **Campaign Analysis** – Campaign performance and effectiveness.
